# 🌱 TaskTracker

Персональный трекер задач с геймификацией. Выполняй задачи, получай опыт, расти дерево прогресса и преврати продуктивность в игру.

## Возможности

- **Задачи** — CRUD с категориями (кастомные эмодзи), сложностью (лёгкая/средняя/сложная), опытом (XP) и дедлайнами
- **Календарь** — годовая сетка 4×3 месяца, каждый день окрашен по количеству выполненных задач
- **Дерево прогресса** — 50 стадий анимированного роста на Canvas (от семени до древа мироздания), растёт с каждым уровнем
- **Система уровней** — каждый следующий уровень требует на 20% больше опыта
- **XP и прогресс-бар** — опыт начисляется за выполнение задач и помодоро-сессии
- **Случайная задача дня** — кнопка в hero-секции
- **Помодоро-таймер** — кастомный таймер с настраиваемым временем и бонусным XP
- **Аналитика** — интерактивные графики (линии, бары, область, точки) по задачам и pomodoro
- **Сводные таблицы** — 4 представления: задачи, категории, помодоро, сложность
- **Экспорт/импорт** — JSON
- **Тёмная/светлая тема** — переключатель в навбаре

## Технологии

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Canvas 2D API (дерево прогресса)
- Recharts (графики)
- localStorage (хранение данных)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run preview  # preview production build
```

# 🌱 TaskTracker

Персональный трекер задач с геймификацией. Выполняй задачи, получай опыт, расти дерево прогресса и преврати продуктивность в игру.

## Возможности

- **Задачи** — CRUD с категориями (кастомные эмодзи), сложностью (лёгкая/средняя/сложная), опытом (XP) и дедлайнами
- **Календарь** — годовая сетка 4×3 месяца, каждый день окрашен по количеству выполненных задач
- **Спорт** — подраздел календаря: создание и планирование тренировок с выбором типа (12 предустановленных + свои), длительностью, заметками и XP. Сохранение своих типов тренировок с возможностью переименования и удаления. Кнопка быстрого перехода из hero-секции.
- **Дерево прогресса** — 50 стадий анимированного роста на Canvas (от семени до древа мироздания), растёт с каждым уровнем
- **Система уровней** — каждый следующий уровень требует на 20% больше опыта
- **XP и прогресс-бар** — опыт начисляется за выполнение задач, помодоро-сессии и тренировки
- **Случайная задача дня** — кнопка в hero-секции
- **Помодоро-таймер** — кастомный таймер с настраиваемым временем и бонусным XP
- **Аналитика** — интерактивные графики (линии, бары, область, точки) по задачам, pomodoro и тренировкам. Вкладка «Спорт» с отдельной статистикой: тренировки по дням, XP, длительность, круговая диаграмма по типам.
- **Сводные таблицы** — 5 представлений: задачи, категории, помодоро, сложность, тренировки (история с датами, типами, длительностью и XP)
- **Экспорт/импорт** — JSON
- **Тёмная/светлая тема** — переключатель в навбаре

## Технологии

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Canvas 2D API (дерево прогресса)
- Recharts (графики)
- localStorage (хранение данных)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run preview  # preview production build
```
